Cockpit is the [modern Linux admin interface](https://cockpit-project.org/).
We release regularly.

Here are the release notes from Cockpit 369 and cockpit-machines 358:


## machines: Drop SPICE package recommendation during install from Fedora 46 and up

The Fedora package for Cockpit Machines used to have a `Recommends: qemu-char-spice` dependency in it and would thus normally cause SPICE support to be installed together with the cockpit-machines package. This will no longer happen. If you want to keep SPICE support, you need to install it explicitly now. SPICE will remain recommended for existing versions, including Fedora 45.
